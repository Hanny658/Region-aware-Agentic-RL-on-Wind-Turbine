The main text carries the positive results (`../paper/NARRATIVE.md`). Everything measured that does not
belong there is listed below, with its evidence, so that nothing is lost and nothing has to be rediscovered
when a referee asks for it. Items **A1 and A2 were pre-registered** in roadmap s59.1 before the runs existed;
see `../paper/NARRATIVE.md` §6 for the three sentences that must appear in the discussion pointing here.

## Two things that are *not* appendix material

- **The superseded baseline (s29/s31) and every number measured over it.** It is not a tuning file - it
  scaled `PC_GS_KP` / `PC_GS_KI` by two scalars, which implies a damping ratio varying 6.8-12.8 % along the
  schedule, so no tuning file can produce those gain tables (s51-s52). Its rows are *wrong*, not *superseded
  by better ones*: they belong in `../archive/`, not in an appendix. The single exception is the one ladder
  row in `../tables/ladder_published_fresh.csv`, which is printed only to explain why the model-based
  controller used to look load-optimal (`../paper/EVIDENCE.md` §7).
- **The composite objective as a reported number.** It stays in the setup and this appendix as the
  campaigns' selection and training objective, under its own name, never as a result, and the symbol *J* is
  the MPC cost function.
