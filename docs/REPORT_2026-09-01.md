# Region-aware Agentic RL on Wind Turbine — 实验结论整合（截至 2026-09-01）

本文件是对 2026-08-29 → 09-01 全部实验的核对与整理。逐日过程与中间表格见
`docs/roadmap_2026-08-30.md`（第 1–12 节），原始数据在 WSL `~/wtrl/exp/*`（每个 run 含
`config.json / episodes.csv / evals.csv / decisions.jsonl / ckpt_* / eval_*.json`，LLM 运行另有
`llm_transcript.jsonl` 全部 prompt/response）。所有数字都可由 `scripts/summarize.py`、
`scripts/dev/{heldout_table,paper_table,per_wind_table,eval_detail,power_mae_table}.py` 复算。

## 1. 实验系统（最终形态）

- **机型/仿真**：NREL 5 MW onshore，OpenFAST 4.2.1（conda-forge），ROSCO v2.10.5 打补丁
  （ZMQ 测量 17→22 通道：+测得桨距、原生桨距命令、当前桨距下限、风速估计、最终命令；C 端持久 socket）。
  恒扭矩（`VS_ConstPower=0`，与基线论文一致）、`PS_Mode=1`、控制步长 10 ms。
- **架构**：ROSCO GSPI + 区域残差 Δβ（oracle 规则分区：原生桨距命令 > 当前下限+0.5° 持续 1 s ⇒ R3，1 s 滞回），
  残差经二阶临界阻尼 damper + 安全层（R2 非负、总命令钳制）。1-DOF toy 数字孪生调用同一 `libdiscon.so`。
- **奖励（统一、区域条件化）**：R2 `w_P(P/P_GSPI−1)`；R3 `w_w·exp(−|δω|/0.02)`；载荷项
  `−λ_L·range_inc`（**10 s 滑窗极差增量**，按后端 GSPI 标定）；动作惩罚 (Δβ/0.1)²。
- **评估（fitness F，任何学习器/监督者不可修改）**：相对同风种子 GSPI，
  **最大化塔基前后 DEL 降幅**，约束能量损失 ≤1%、R3 转速 std 不劣于 GSPI；
  分层报告 **strict**（不劣于）/ **tol2**（转速容差 2%，工程等价）/ **degraded**。
- **PPO**：论文 Table II 超参 + **γ=0.998 / GAE-λ=0.98**（关键修正，见 F4）、探索 σ 状态无关、
  观测 running normalization（采样一致性修正）、按 wave（8 episode）更新、护栏
  （违约才回滚到历史最优状态）+ best-checkpoint 选择。
- **监督者**（每 30 episode，评估 S1+S2）：`guard`（固定权重）/ `llm_fork`（LLM 3 候选 + 单 wave
  分叉验证择优，RHyVE 式）/ `random_fork`（同分叉、随机候选）/ `schedule`（回放 LLM 蒸馏课程表）。

## 2. 已核对的核心结论

**F1（主结论）：区域分工 > 单一策略，且结论只在约束下成立。**
held-out（S3–S6，3 RL 种子）：9 个监督 spec run **全部 strict** 且在论文四指标上全部改善
（功率 MSE +0.5…+22%、转速 MSE 同、塔基 DEL +10…+23%、叶根 DEL +2.8…+8%）；mono 0/9 strict，
转速/功率 MSE 每个种子都劣于 GSPI（−1.7…−4.4%），其 tol2 层的减载并不大于 spec 的 strict 层。
区域 one-hot 不能拯救 mono（toy 与 OpenFAST 均验证）。
*注意表述边界*：mono 的失败模式是"用调速换减载"，在允许 2% 转速容差的口径下 mono 是可用的——
结论必须绑定约束口径（分层报告因此是必要组件）。

**F2（区域分工的物理解耦）**：R3 残差只改善调速（std 比 0.88–1.00、MAE 比 0.86–1.00），
对塔基 DEL 贡献 ≈0（r3only-all-winds：−0.04%）；**塔基减载几乎全部来自 R2 的削峰变桨**
（推力↓，代价 0.07–0.68% 能量）。R2 桨距 agent 在塔基目标下有真实职责（"冻结 R2"决定已撤回）；
叶根疲劳 DEL 用集体变桨只能动 ±3–8%（与论文 15 MW 的 0.2% 一致）。

**F3（奖励设计三次迭代，方法学结论）**：m=10 的 DEL 由 130 s 内最大 1–5 个循环决定；
`|M|` 水平惩罚 → 载荷反馈变桨激发挥舞模态（DEL +17…+740%）；`|ΔM|` 增量 → 压高频小波动、λ≥3 失稳；
**10 s 滑窗极差增量**与 DEL 相关 0.83–1.0、训练稳定。λ 可用区间窄（0.3–1 起步），冷启动 λ=3 必崩，
但**学会之后逐步升 λ 可行**（课程效应，最早由 LLM 发现）。

**F4（根因修正，OpenFAST 特有）**：γ=0.99 在 10 ms 步长下（1 s 视界）对 ~3 s 塔架模态短视,
纯调速奖励也会学出激发塔架的快速变桨（转速 std 比恶化至 1.27、桨距行程 39→57°）；
γ=0.998（5 s）修复（0.93）。此前的 OpenFAST 方法排序全部因此作废并重跑。
其余已修的实现要点：观测归一化统计须用采样时刻的版本；分叉/评估端口与工作目录按 run 隔离；
ckpt_last 经常 degraded，**best-checkpoint 选择必不可少**。

**F5（LLM 的作用，3 种子后的诚实版本）**：
- 监督（不论哪种）优于固定权重：F 均值 15.4–15.6 vs 13.2，且 9/9 strict（guard 2/3）。
- 但 `llm_fork`（15.4±4.0）、`random_fork`（15.6±5.4）、`schedule`（15.6±0.3）**三者打平**；
  P5 单种子的 LLM +5 优势属于种子噪声。
- **无验证的 LLM 单候选监督有害**：训练评估种子上 strict、held-out 违约（转速 1.04+），双种子评估
  也救不了——LLM 提议必须经分叉验证或蒸馏为课程表后使用。
- LLM 的**可归因贡献**：(a) 发现 λ 课程表（schedule 即其轨迹蒸馏，σ=0.3 最稳、运行零 API 成本）；
  (b) 探索期的诊断多次指对方向（塔架频带占比、约束裕量、12.5 m/s 瓶颈）。
  "在线 LLM > 随机+验证"需 ≥5–8 种子才能分辨（Slurm 项）。
- 成本：llm_fork 每次训练仅 5 次调用（~24k prompt / 5.7k completion tokens）。

**F6（与基线的关系）**：相对 GSPI 见 F1；**与 MPC 无对比**（未实现，open item）；
与论文 15 MW 数字不可直接比（机型与目标权重不同：我们载荷优先，调速增益 4–8% vs 论文 23%，
塔基 15% vs 论文 4.5%）。

**F7（toy 数字孪生的边界）**：toy 与 OpenFAST 在 GSPI 行为上高度吻合，适合筛机制/奖励/超参
（本项目三次奖励迭代都在 toy 上完成），但 (a) toy 的 R2"减载"是对 ζ=0.05 挥舞模态的主动阻尼、
不迁移；(b) toy 策略零样本上 OpenFAST 完全失败；(c) toy 里 negative transfer 的表现形式与
OpenFAST 不同（toy: R3 学不动；OpenFAST: 调速被牺牲）。孪生的正确用途是机制验证与 LLM 分叉试跑。

## 3. 未决事项（按优先级）

1. **监督变体分辨**：llm_fork vs random_fork vs schedule，≥5–8 种子（Slurm/新机器）。
2. **MPC 基线**（若论文需要）：LPV-MPC 复现，约 2–3 天。
3. R2 扭矩残差（ROSCO 补丁 1 行 + Controllers.f90 应用 `ZMQ_TorqueOffset`）：给 R2 能量侧目标。
4. Route B（Eureka 式奖励代码进化，fitness 已就绪）；学习型 router（MLP/KAN）——优先级最低。
5. 15 MW / IEA-15 monopile 扩展（config 驱动，主要是算力问题）。

## 4. 迁移到新笔电

见 `scripts/wsl/bootstrap.sh`（在新机 WSL 内一条命令完成环境+编译+模板+风库+基线）。要点：

  风库与基线也可在新机重新生成（~40 min），但**若要继续对比必须用同一批 .bts 文件**（建议直接拷贝）。
- Claude 记忆在 `C:\Users\<user>\.claude\projects\<此项目>\memory\`，如需新机继续同一上下文可一并复制。
- `~/wtrl/run.sh` 由 bootstrap 按新机仓库路径自动生成。
